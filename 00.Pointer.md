# C++ Pointers to Linked Lists — Complete Beginner Notes

## Goal

These notes are designed to build one continuous chain of understanding:

**Variables → Memory → Addresses → Pointers → Dynamic Memory → `struct` → Nodes → Linked Lists**

Do not jump directly to linked lists. Linked lists become much easier once pointers are clear.

---

# Part 1: Variables and Memory

## 1. What is a variable?

```cpp
int x = 10;
```

`x` is a variable that stores the value `10`.

Conceptually, memory may look like this:

```text
Variable     Value
x            10
```

A variable is stored somewhere in computer memory. That location has an **address**.

Conceptually:

```text
Variable     Value     Address
x            10        1000
```

`1000` is only an example. Real memory addresses are usually shown in hexadecimal form.

---

# Part 2: The Address-of Operator `&`

## 2. Getting the address of a variable

The operator `&` means:

> Give me the address of this variable.

```cpp
int x = 10;

cout << &x;
```

Conceptually:

```text
x  = 10
&x = address where x is stored
```

If `x` is stored at address `1000`:

```text
x   → 10
&x  → 1000
```

Important distinction:

```cpp
cout << x;   // value
cout << &x;  // address
```

---

# Part 3: What Is a Pointer?

## 3. Pointer definition

A **pointer is a variable that stores the address of another variable**.

Example:

```cpp
int x = 10;

int* ptr = &x;
```

Break this into pieces.

### `x`

```cpp
int x = 10;
```

Conceptually:

```text
Address 1000
┌───────┐
│  10   │  ← x
└───────┘
```

### `&x`

```cpp
&x
```

means:

```text
1000
```

It gives the address of `x`.

### `ptr`

```cpp
int* ptr = &x;
```

`ptr` stores the address of `x`.

```text
ptr contains: 1000

ptr
┌─────────┐
│  1000   │
└─────────┘
     │
     ▼
Address 1000
┌─────────┐
│   10    │ ← x
└─────────┘
```

---

# Part 4: Understanding `*`

The symbol `*` has different meanings depending on where it is used.

## 4.1 In a declaration

```cpp
int* ptr;
```

Here `*` means:

> `ptr` is a pointer to an `int`.

So `ptr` can store the address of an integer.

---

## 4.2 When accessing through a pointer

```cpp
*ptr
```

Here `*` means:

> Go to the address stored inside `ptr` and access the value there.

Example:

```cpp
int x = 10;
int* ptr = &x;

cout << *ptr;
```

Output:

```text
10
```

Why?

```text
ptr contains address of x
             ↓
          [ x = 10 ]

*ptr means:
go to that address
and read the value

Result = 10
```

This operation is called **dereferencing** a pointer.

---

# Part 5: The Four Most Important Expressions

```cpp
int x = 10;
int* ptr = &x;
```

| Expression | Meaning |
|---|---|
| `x` | Value stored in `x` |
| `&x` | Address of `x` |
| `ptr` | Address stored in the pointer |
| `*ptr` | Value at the address stored in `ptr` |

Conceptually:

```text
x       = 10
&x      = 1000
ptr     = 1000
*ptr    = 10
```

---

# Part 6: Changing a Variable Through a Pointer

```cpp
int x = 10;
int* ptr = &x;

*ptr = 50;
```

Now:

```cpp
cout << x;
```

Output:

```text
50
```

Why?

```text
ptr
 │
 │ stores address of x
 ▼

┌───────────┐
│ x = 10    │
└───────────┘
```

When we write:

```cpp
*ptr = 50;
```

we say:

> Go to the memory address stored in `ptr` and change the value there to `50`.

So:

```text
x changes from 10 → 50
```

# Part 7: Pointer and `nullptr`

A pointer does not always have to point to something.

```cpp
int* ptr = nullptr;
```

`nullptr` means:

> This pointer currently points to nothing.

Conceptually:

```text
ptr
 │
 ▼
nullptr
```

This is safer than leaving a pointer uninitialized.

# Part 8: Dynamic Memory and `new`

Until now:

```cpp
int x = 10;
```

creates a normal variable.

But sometimes we want to create data dynamically while the program is running.

Example:

```cpp
int* ptr = new int;
```

`new int` creates an integer dynamically and returns its address.

```cpp
*ptr = 10;
```

Conceptually:

```text
ptr
 │
 ▼
┌───────────┐
│    10     │
└───────────┘
```

We can also write:

```cpp
int* ptr = new int(10);
```

---

## Important: `delete`

If we allocate memory using `new`, we should release it when it is no longer needed.

```cpp
delete ptr;
ptr = nullptr;
```

# Part 9: Why Do Linked Lists Need Pointers?

Suppose we have three values:

```text
10    20    30
```

An array can store them together.

```text
[10][20][30]
```

But a linked list stores values as separate **nodes** and connects them using addresses.

```text
[10 | address] → [20 | address] → [30 | nullptr]
```

The address tells us where the next node is.

This is why pointers are essential.

---

# Part 10: What Is a `struct`?

A `struct` allows us to group related variables.

Example:

```cpp
struct Student {
    int id;
    int age;
};
```

This is only a blueprint.

It describes what a `Student` looks like.

```text
Student
├── id
└── age
```

It does not yet create an actual student.

To create one:

```cpp
Student s;
```

Now `s` contains:

```text
s
├── id
└── age
```

# Part 11: Creating a Node

A linked list needs a structure that stores:

1. The actual data.
2. The address of the next node.

```cpp
struct Node {
    int data;
    Node* next;
};
```

This means every `Node` has:

```text
Node
┌─────────────────┐
│ int data        │
├─────────────────┤
│ Node* next      │
└─────────────────┘
```

## Understanding `Node* next`

```cpp
Node* next;
```

means:

> `next` is a pointer that can store the address of another `Node`.

This is how one node connects to another node.

---

# Part 12: What Does `Node* first = new Node();` Mean?

Consider:

```cpp
Node* first = new Node();
```

This line has three important parts.

## Step 1: `Node* first`

```cpp
Node* first;
```

Create a pointer named `first`.

It can store the address of a `Node`.

Conceptually:

```text
first
┌─────────────┐
│ address     │
└─────────────┘
```

---

## Step 2: `new Node()`

```cpp
new Node()
```

Create a new `Node` dynamically.

The node contains:

```text
┌─────────────────┐
│ data            │
├─────────────────┤
│ next            │
└─────────────────┘
```

`new Node()` returns the address of that newly created node.

---

## Step 3: Store the address

```cpp
Node* first = new Node();
```

The address returned by `new Node()` is stored in `first`.

Conceptually:

```text
first
┌───────────┐
│ address   │
└───────────┘
      │
      ▼

┌─────────────────┐
│ data            │
├─────────────────┤
│ next            │
└─────────────────┘
```

Important:

> `first` is not the actual node. `first` stores the address of the node.

# Part 13: Understanding `->`

Suppose:

```cpp
Node* first = new Node();
```

Since `first` is a pointer to a node, we use `->` to access members of that node.

```cpp
first->data = 10;
first->next = nullptr;
```

Meaning:

> Go to the node whose address is stored in `first`, then access its `data`.

Conceptually:

```text
first
  │
  ▼

┌─────────────────┐
│ data = 10       │
│ next = nullptr  │
└─────────────────┘
```

You can think of:

```cpp
first->data
```

as:

```cpp
(*first).data
```

But `first->data` is easier to read.

```cpp
Node* first = new Node();

first->data = 10;
```

Conceptually:

```text
first
  │
  ▼

└────────────────────┘          │
                                ▼
                           ┌────────────────────┐
                           │ data = 20          │
                           │ next = nullptr     │
                           └────────────────────┘
```

```text

```

# Part 15: What Is a Linked List?

A **linked list** is a collection of nodes.

Each node stores:

```text
data + address of next node
```

Example:

```text
head
 ↓
[10 | •] → [20 | •] → [30 | nullptr]
```

The first pointer is commonly called `head`.

```cpp
Node* head = first;
```

`head` stores the address of the first node.

If:

```cpp
head == nullptr
```

the linked list is empty.

---

# Part 16: Traversing a Linked List

Suppose:

```text
head
 ↓
10 → 20 → 30 → nullptr
```

We start at `head` and keep moving to the next node.

```cpp
Node* current = head;

while (current != nullptr) {
    cout << current->data << " ";
    current = current->next;
}
```

Step by step:

```text
current = first node
Print 10

current = current->next
Move to second node
Print 20

current = current->next
Move to third node
Print 30

current = current->next
current becomes nullptr

Stop
```

# Part 17: Insert at the Beginning

Suppose:

```text
head
 ↓
10 → 20 → 30
```

We want to insert `5`.

Create a new node:

```text
5
```

Then connect it to the current head:

```text
newNode → 10 → 20 → 30
```

Then move `head`:

```text
head
 ↓
5 → 10 → 20 → 30
```

Code:

```cpp
void insertAtBeginning(Node*& head, int value) {
    Node* newNode = new Node();

    newNode->data = value;
    newNode->next = head;

    head = newNode;
}
```

Order matters.

Do this:

```cpp
newNode->next = head;
head = newNode;
```

If you change `head` first, you may lose the connection to the old first node.

---

# Part 18: Insert at the End

To insert at the end:

1. Create a new node.
2. Find the last node.
3. Connect the last node to the new node.

```cpp
void insertAtEnd(Node*& head, int value) {
    Node* newNode = new Node();

    newNode->data = value;
    newNode->next = nullptr;

    if (head == nullptr) {
        head = newNode;
        return;
    }

    Node* current = head;

    while (current->next != nullptr) {
        current = current->next;
    }

    current->next = newNode;
}
```

---

# Part 19: Delete the First Node

Suppose:

```text
head
 ↓
10 → 20 → 30
```

We save the old first node:

```cpp
Node* temp = head;
```

Move `head`:

```cpp
head = head->next;
```

Now:

```text
head
 ↓
20 → 30
```

Delete the old node:

```cpp
delete temp;
```

Complete function:

```cpp
void deleteFirst(Node*& head) {
    if (head == nullptr) {
        return;
    }

    Node* temp = head;
    head = head->next;

    delete temp;
}
```

# Part 20: Complete Basic Linked List Program

```cpp
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
};

void insertAtEnd(Node*& head, int value) {
    Node* newNode = new Node();

    newNode->data = value;
    newNode->next = nullptr;

    if (head == nullptr) {
        head = newNode;
        return;
    }

    Node* current = head;

    while (current->next != nullptr) {
        current = current->next;
    }

    current->next = newNode;
}

void printList(Node* head) {
    while (head != nullptr) {
        cout << head->data << " ";
        head = head->next;
    }

    cout << endl;
}

int main() {
    Node* head = nullptr;

    insertAtEnd(head, 10);
    insertAtEnd(head, 20);
    insertAtEnd(head, 30);

    printList(head);

    return 0;
}
```

Output:

```text
10 20 30
```

# Part 21: Why `Node*& head`?

Consider:

```cpp
void insertAtBeginning(Node*& head, int value)
```

`Node*&` means:

> Pass the pointer itself by reference.

Why?

Because the function may need to change `head`.

For example:

```cpp
head = newNode;
```

If the pointer is not passed correctly, changes to `head` may not affect the original pointer in `main()`.

For a beginner, remember:

```cpp
Node* head
```

means:

> A pointer to a Node.

```cpp
Node*& head
```

means:

> A reference to a pointer to a Node.

# Part 22: Time Complexity

| Operation | Time Complexity |
|---|---|
| Access first node | O(1) |
| Insert at beginning | O(1) |
| Delete first node | O(1) |
| Search for value | O(n) |
| Insert at end (without tail) | O(n) |
| Access by index | O(n) |

Unlike arrays, linked lists cannot directly jump to an index.

For example, to reach index `5`, we must follow:

```text
head → node → node → node → node → node
```

# Practice Questions with Solutions

# Question 1: Print All Elements

## Problem

Write a function to print every element of a linked list.

Example:

```text
10 → 20 → 30
```

Output:

```text
10 20 30
```

## Solution

```cpp
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
};

void printList(Node* head) {
    Node* current = head;

    while (current != nullptr) {
        cout << current->data << " ";
        current = current->next;
    }
}

int main() {
    Node* first = new Node{10, nullptr};
    Node* second = new Node{20, nullptr};
    Node* third = new Node{30, nullptr};

    first->next = second;
    second->next = third;

    printList(first);

    return 0;
}
```

### Logic

```text
Start at first node
↓
Print data
↓
Move to next
↓
Repeat until nullptr
```

# Question 2: Count Nodes

## Problem

Return the number of nodes in a linked list.

Example:

```text
10 → 20 → 30 → 40
```

Answer:

```text
4
```

## Solution

```cpp
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
};

int countNodes(Node* head) {
    int count = 0;

    while (head != nullptr) {
        count++;
        head = head->next;
    }

    return count;
}
```

### Logic

For every node:

```text
Visit node
↓
Increase count
↓
Move to next node
```

# Question 4: Search for a Value

## Problem

Check whether a given value exists in the linked list.

Example:

```text
10 → 20 → 30
```

Search for:

```text
20
```

Answer:

```text
Found
```

## Solution

```cpp
bool search(Node* head, int target) {
    while (head != nullptr) {

        if (head->data == target) {
            return true;
        }

        head = head->next;
    }

    return false;
}
```

### Logic

```text
Start at head
↓
Is data equal to target?
↓
Yes → return true
No  → move to next node
↓
Reach nullptr → return false
```

# Question 5: Reverse a Linked List

## Problem

Reverse:

```text
10 → 20 → 30 → nullptr
```

Into:

```text
30 → 20 → 10 → nullptr
```

## Solution

```cpp
Node* reverseList(Node* head) {
    Node* previous = nullptr;
    Node* current = head;

    while (current != nullptr) {
        Node* nextNode = current->next;

        current->next = previous;

        previous = current;
        current = nextNode;
    }

    return previous;
}
```

## Detailed Logic

Initially:

```text
previous = nullptr
current = 10
```

Save the next node:

```text
nextNode = 20
```

Reverse the connection:

```text
10 → nullptr
```

Move pointers:

```text
previous = 10
current = 20
```

Repeat:

```text
previous = 20 → 10
current = 30
```

Finally:

```text
previous = 30 → 20 → 10
current = nullptr
```

Return:

```cpp
return previous;
```

Because `previous` is now the new head.

# Final Mental Model

Remember this complete chain:

```text
Variable
↓
Stored somewhere in memory
↓
Memory location has an address
↓
Pointer stores an address
↓
Pointer can point to another variable/object
↓
A Node contains data + pointer
↓
Pointer connects one Node to another
↓
Multiple connected Nodes form a Linked List
```
